Binary → Denary

\[ 10111_{2} \]
= \(1\times2^{\textcolor{#facc15}{4}}\) + \(0\times2^{\textcolor{#facc15}{3}}\) + \(1\times2^{\textcolor{#facc15}{2}}\) + \(1\times2^{\textcolor{#facc15}{1}}\) + \(1\times2^{\textcolor{#facc15}{0}}\)
= 16 + 0 + 4 + 2 + 1
\[ = 23_{10} \]

Denary → Binary

Peel off powers of 2 from \(23_{10}\):

\(23 = 16 + 7\)→\(1\times2^{\textcolor{#facc15}{4}}\)
\(7 = 4 + 3\)→\(1\times2^{\textcolor{#facc15}{2}}\)
\(3 = 2 + 1\)→\(1\times2^{\textcolor{#facc15}{1}}+1\times2^{\textcolor{#facc15}{0}}\)
\[ 23_{10} = 10111_{2} \]
