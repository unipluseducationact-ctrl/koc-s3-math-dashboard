Place Value & Expanded Form

Every digit is a coefficient times a power of the base.

\[ \text{digit} \times \text{base}^{\text{place}} \]

Denary uses base \(10\). Binary uses base \(2\).

Binary → Denary

Evaluate the powers of 2

\[ 10111_{2} \]
\[ = 1\times 2^4 + 0\times 2^3 + 1\times 2^2 + 1\times 2^1 + 1\times 2^0 \]
\[ = 16 + 0 + 4 + 2 + 1 \]
\[ = \hl{23_{10}} \]
Denary → Binary

Factor into \(a \times 2^{b}\)

Convert \(23_{10}\) by peeling off the largest power of 2 each time.

\(23 = 16 + 7\)
→
\(1\times 2^4\)
\(7 = 4 + 3\)
→
\(1\times 2^2\)
\(3 = 2 + 1\)
→
\(1\times 2^1 + 1\times 2^0\)
\[ 23_{10} = 10111_{2} \]
